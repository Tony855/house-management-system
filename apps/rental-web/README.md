# Rental Portal

独立租房前端应用边界。后续在此建立独立 HTML 入口、路由、登录客户端、cookie 名称、CSP、构建与部署流水线。

- App audience: `rental`
- API service: `rental-api`
- Tenant identity and business data: tenant-owned rental database only
- Never reuse hotel/property/super-admin access tokens or shared browser auth state.

This directory is an application boundary scaffold, not a production-ready portal yet.
